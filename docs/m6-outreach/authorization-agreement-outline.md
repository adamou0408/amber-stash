# 收納師方法論授權合約 Outline

> 用途：M6 啟動時與收納師簽約用的條款大綱。
> **本檔不是合約全文**，是給律師起草用的結構化要點清單。
> 撰寫日期：2026-05-16
> 適用法域：中華民國（台灣）。若邀請對象在港澳 / 馬來西亞 / 日本，需個別調整。

---

## 0. 前言（建議律師加入）

- 雙方身份：「方法論作者」（收納師） / 「授權方」（Amber Stash 營運公司）
- 背景：作者為專業整理收納實務工作者，授權方營運居家收納 app。
- 目的：將作者的整理收納方法論轉化為結構化規則（JSON），於 app 內提供使用者選擇與訂閱。

---

## 1. 授權範圍

### 1.1 授權標的
- 作者的「整理收納方法論」之**規則邏輯**（轉為 `Methodology` JSON 結構）
- 方法論的**文字敘述**（建議標題、內文、模板）
- 作者的**姓名、頭像、簡介**（用於 app 內 attribution 顯示）
- 不包含：作者已出版的書籍 / 線下課程內容之原文重製（除非雙方另行約定）

### 1.2 授權形式
- **獨家 vs 非獨家**：建議「**Amber Stash 平台類別獨家**」，即作者不得在其他「居家收納 app」上線同一方法論的結構化規則版本，但仍可在書籍、課程、社群、影片中傳授同樣理念。
- **地域**：全球繁中市場（台灣、港澳、海外華語）；若擴及日韓 / 英文版，需簽附約。
- **媒介**：App 內顯示、行銷素材引用、社群推廣截圖。
- **期限**：建議首期 **2 年**，到期前 60 天若任一方未提出異議則自動續約 1 年。

### 1.3 再授權
- Amber Stash **不得**將作者方法論再授權給第三方營利使用，除非另行書面同意並另計分潤。
- Amber Stash **可**將方法論的「結構化規則 JSON」用於 app 內 AI 模型訓練 / fine-tune，但訓練成果不得分離銷售。

→ **需要律師審閱：「AI 訓練用途」屬授權範圍還是衍生用途，影響分潤計算。**

## 2. 智慧財產權歸屬

### 2.1 原方法論 IP
- **作者保有**其方法論的著作人格權與原始著作財產權。
- Amber Stash 僅取得「依本合約使用」之授權，不取得所有權。

### 2.2 結構化版本 IP（重要）
- 「方法論的 JSON 結構化版本」屬「演繹著作」性質。
- 建議約定：**Amber Stash 持有結構化版本的編輯著作權**（因為實際做 schema 設計 / 規則拆解的是 app 團隊）；但作者可隨時要求查閱、修正。
- 若雙方終止合約，Amber Stash 應**下架**結構化版本，但編輯著作權保留（不再使用即可）。

→ **需要律師審閱：演繹著作 / 編輯著作權的所有權劃分，特別是終止後的處置。**

### 2.3 商標 / 識別
- 若作者個人品牌已註冊商標（例：「○○ 法」），授權範圍須明列商標使用方式。
- Amber Stash 不得將作者姓名 / 商標用於與收納無關之產品線。

## 3. 分潤模式（給三個方案讓作者選）

> 詳細比較見 `pricing-model.md`。本節僅列合約條款骨架。

### 方案 A：純訂閱分潤
- 使用者訂閱該方法論之月費收入，作者抽 **30%**（提案區間 25-35%）
- 結算週期：**月結**，次月 15 日前匯款
- 配套：作者享免費內部後台查看訂閱數、活躍使用者數（去識別化）

### 方案 B：一次性買斷
- 簽約時一次性支付 NT$ **80,000-150,000**（依方法論完整度與作者知名度議定）
- 方法論版權永久授權給 Amber Stash 使用，作者不再有分潤
- 適合：希望單次取得稿酬、不想長期綁定的作者

### 方案 C：訂閱分潤 + 銷售箱抽成
- 訂閱分潤同方案 A，比例可調降為 **20%**
- 加上：因該方法論觸發 / 推薦的客製收納箱訂單，作者額外抽 **3-5%** of 箱子毛利
- 結算：同月結
- 適合：對 app「四角飛輪」有信心、願意一起做大盤的作者

### 共通條款
- 三方案均明列**最低保證金（minimum guarantee）**：簽約時付 NT$ **20,000** 作為內容準備費，未來分潤超過該金額後不再扣抵（即視為簽約金）
- 退費 / 退訂事件：使用者退費部分按比例扣回作者分潤（從次月扣抵）
- 稅務：作者自行申報執行業務所得，Amber Stash 依規定開立扣繳憑單

→ **需要律師審閱：扣繳憑單適用、跨境作者（港澳 / 日）扣繳率差異。**

## 4. 內容義務（作者方）

### 4.1 初始交付
- 簽約後 **30 天內**交付：
  - 方法論完整文字描述（500-2000 字）
  - 至少 **5 條決策規則**（DecisionRule）的人話版本，由 app 團隊轉 JSON
  - 至少 **3 條購物建議規則**（ShoppingRule）
  - 個人簡介、頭像、3-5 句 bio
- 交付後 **14 天內**雙方確認 JSON 結構化版本與作者本意一致（書面 / Email 簽核）

### 4.2 持續更新
- 作者每 **6 個月**至少提交 1 次「方法論版本更新」，可為：
  - 新增 / 修正規則
  - 文字敘述微調
  - 季節性建議補充
- 若連續 2 個更新週期（即 12 個月）未提交，視為「自動進入維護期」，Amber Stash 可酌減分潤至 **15%** 直到下次更新提交。

### 4.3 Bug fix 義務
- 使用者回報「規則建議與方法論不符 / 文字錯誤」時：
  - app 團隊 48 小時內通知作者
  - 作者 **14 天內**確認 / 修正
  - 期間 app 端可暫時下架該條規則
- Bug fix 不算 4.2 條的「更新」次數。

### 4.4 推廣義務（軟性）
- 作者上線時，於自身平台（IG / FB / YT）**至少做 1 次公開推廣貼文**，內容雙方協商
- 後續推廣為自願，但 Amber Stash 可提供素材包

## 5. 內容義務（Amber Stash 方）

- 於 app 內顯示作者 attribution（姓名、頭像、連結到作者頁）
- 提供作者**內部後台**查看：訂閱數（時間序列）、活躍率、規則命中熱度
- 提供作者**免費永久使用** Amber Stash app 全部進階功能
- 不修改方法論「核心邏輯」未經作者同意；僅做 schema 適配 / typo 修正可單方執行

## 6. 終止條款

### 6.1 任一方可終止
- **重大違約**：另一方書面通知後 30 天內未補正
- **品牌風險事件**：作者發生重大爭議事件（依社會通念）/ Amber Stash 違反隱私法規等，另一方可立即終止
- **服務終止**：Amber Stash app 整體停止營運（提前 90 天通知）

### 6.2 作者單方終止
- **無原因終止權**：簽約滿 **12 個月**後，作者得提前 90 天書面通知終止
- 終止後該方法論於 app 內**下架日**：通知後第 90 日
- 已訂閱使用者的處置：
  - 既有訂閱者繼續享有至本訂閱週期結束
  - 不再開放新訂閱
  - 結算最後一個月分潤

### 6.3 Amber Stash 單方終止
- **無原因終止權**：簽約滿 **6 個月**後，可提前 60 天通知終止
- 若因「訂閱數 3 個月低於 20 人」終止，需支付作者 NT$ **15,000** 終止補償

### 6.4 終止後義務
- 雙方繼續保密義務 5 年
- Amber Stash 不再使用作者姓名 / 頭像 / 商標
- 結構化版本 JSON 保留於內部備份（不對外使用），不得用於 AI 訓練或重新上線

→ **需要律師審閱：「6 個月」「12 個月」「90 天通知」具體期間是否合理；補償金額是否公平。**

## 7. 保證與責任

### 7.1 作者保證
- 方法論為作者**原創或合法取得授權**（特別是 KonMari 認證顧問需附認證資料）
- 未侵害任何第三方著作權 / 商標權
- 若有侵權主張，作者負首要法律與賠償責任

### 7.2 Amber Stash 保證
- 依約使用作者方法論，不超範圍
- 隱私資料處理符合《個人資料保護法》
- 訂閱金流符合金管會相關規範

### 7.3 責任上限
- 任一方對另一方的賠償責任，**以過去 12 個月內已支付給作者之分潤總額為上限**（除故意 / 重大過失）

→ **需要律師審閱：責任上限條款是否會被法院視為顯失公平。**

## 8. 機密 / 隱私 / 資料

### 8.1 機密資料
- 訂閱數、營收、AI 模型細節、其他作者合作條件 → 機密
- 機密義務存續期：合約終止後 **5 年**

### 8.2 使用者資料
- Amber Stash 提供給作者後台的數據**全部去識別化**（不含任何單一使用者可識別資訊）
- 作者不得嘗試還原 / 反向識別使用者
- 違反者視為重大違約

---

## 9. 爭議解決

- **先行協商**：爭議發生後 30 天內雙方應以善意協商
- **調解**：協商不成，先進行 1 次調解（可由中華民國仲裁協會或雙方議定的調解人主持）
- **管轄法院**：**台灣台北地方法院**為第一審管轄法院
- **準據法**：中華民國法律

→ **需要律師審閱：是否採仲裁優於訴訟、跨境作者的準據法調整。**

---

## 10. 一般條款

- **修改**：本合約修改須雙方書面同意
- **可分割性**：任一條款無效不影響其餘條款效力
- **通知方式**：Email + 雙掛號信並行；Email 寄送日視為通知日
- **不可抗力**：天災、戰爭、政府命令、網路 / 雲端服務商重大事故 → 暫停義務不負違約責任
- **整份合約**：本合約取代雙方先前一切口頭 / 書面協議

## 額外建議（給創辦人）

- 不要追求一份「完美合約」才開始邀請。**先做「簡版 MOU」**（單頁意向書）讓 3 位收納師簽，正式合約可以在 PoC 期間慢慢談。
- 簽約金部分對個人作者比例上很重要 — NT$ 20,000 minimum guarantee 是 anchor，能幫破冰。
- 若預算極限，可先做「**非獨家 + 純訂閱分潤 + 6 個月 PoC**」最輕量授權，談判摩擦最低。
