### 觀察重點（punch lines）

- **沒有任何一個競品同時做好「物品 inventory + 空間配置 + AI 推薦」這三件事**。Sortly 強在 inventory，Planner 5D 強在空間，REimagine 強在 AI，但三者互不交集。
- **拍照識物**這欄絕大多數是 ❌ 或 🟡。Sortly 只拍照不辨識，Lens 辨識但不入庫——這是明顯空白。
- **AI 收納建議**全欄掛零。整個品類沒有任何 app 真的回答「我的東西應該怎麼放」。
- 訂閱制已是主流（7/12），消費者付費教育已完成。

## 第三部分：機會缺口分析

### 差異化機會點（3-5 個 angle）

1. **「拍照即入庫 + 自動分類」是品類空白**
   Sortly 要使用者手動 key，Lens 認得但不存。把 GPT-4V / Gemini Vision 等級的辨識直接綡進 inventory flow，就是一個沒人做的 0→1。

2. **AI 收納建議是真正的藍海，但要綡「具體空間」才有用**
   光說「衣服分顏色掛」是 Pinterest 等級。我們的差異化必須是「掃你家衣櫃 → 給你你家衣櫃的方案」。把 Magicplan 的空間掃描 + 物品辨識 + LLM 推薦串起來。

3. **「買收納盒」這個 high-intent moment 沒人收割**
   消費者整理時最痛的就是「我需要什麼尺寸的盒子」。Houzz 賣設計感，IKEA 賣自家。沒人做「依你家空間尺寸 + 你的物品量，推薦該買哪幾個收納盒」的精準導購——這同時是商業模式。

4. **季節輪替/換季提醒是被低估的 retention hook**
   Sortly 有保固提醒但很制式。「夏天到了，你冬衣該收起來，這 12 件建議裝進這 2 個箱子放在衣櫃上層」這種 contextual nudge 才是讓 app 留下來的理由。

5. **家庭協作 + 角色（「誰的東西」）**
   Sortly 的協作偏 B2B。家庭場景的真正痛點是「老公的襪子不要混到我的抽屜」——把物品 owner 和共用空間的 ACL 做對，是 family TA 的鉤子。

### 最大威脅

**Sortly 是最大威脅，但威脅有限。**
- 為什麼像：他們最接近「物品 inventory + 訂閱制 + 家庭」這個組合。
- 為什麼有限：他們 6 年沒有大改架構，AI 完全沒進場，UX 是 2018 年的味道。只要我們在拍照識物 + AI 推薦上做出體感差距，就有空間切走他們的 family 用戶。
- **次要威脅**：IKEA / Amazon 哪天決定把 AR + AI 推薦 + inventory 整起來。但大公司動作慢，這是 2-3 年的時間窗。

### MVP 優先順序（依市場驗證的 unmet need）

| 排序 | 功能 | 為什麼是這個順序 |
|---|---|---|
| **P0** | 拍照識物 + 自動分類 + 物品清單 | 整個 app 的入口，且 Sortly 沒做、Lens 沒接 inventory，是最大缺口。沒這個其他都白搭。 |
| **P0** | 基礎標籤 / 房間-收納位置兩級結構 | 為後續 AI 推薦準備結構化資料。先不要做完整 2D 平面圖。 |
| **P1** | AI 收納建議（先文字 + 圖卡，不做 3D） | 在 P0 累積物品資料後馬上接，是付費轉換的 hero feature。3D 太重，MVP 跳過。 |
| **P1** | 收納用品購物清單（先做「建議清單」，不做交易閉環） | 用 affiliate / 外連先驗證 intent，不要一開始做商城。 |
| **P2** | 家人共享 | 留下家庭用戶的 retention 機制，但單人能跑通才做多人。 |
| **P2** | 換季 / 保固提醒 | retention loop，等 DAU 數據出來再決定通知策略。 |
| **P3** | 2D / 3D 空間規劃 | Planner 5D 已經把這條路做爛了，我們不要正面對撞。要做就用 Magicplan 風格的相機掃描而不是手繪。 |

### 給創辦人的 actionable 結論

- **不要把自己定位成 "Sortly + AI"，要定位成 "AI 收納顧問，inventory 只是 side effect"**。前者只是功能加法，後者是品類重定義。
- **第一個版本只要做對一件事：使用者拍 10 張照片，3 分鐘後得到一個具體的「你家的收納改造方案 + 該買的 3 個收納盒」**。其餘都是支援這個 magic moment 的鷹架。
- **收費點放在「生成方案」而不是「儲存物品」**。inventory 免費無限，AI 推薦次數收費——讓免費用戶幫你做資料，付費用戶買洞察。
- **避開 3D 規劃這個坑**。資源不夠又打不贏 Planner 5D，且不是用戶真正要的東西。
