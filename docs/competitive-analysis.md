> 對象：自家「居家收納推薦」app（React Native + Expo）
> 核心：物品清單、AI 收納推薦、空間規劃、收納用品購物清單

### 觀察重點（punch lines）

- **沒有任何一個競品同時做好「物品 inventory + 空間配置 + AI 推薦」這三件事**。Sortly 強在 inventory，Planner 5D 強在空間，REimagine 強在 AI，但三者互不交集。
- **拍照識物**這欄絕大多數是 ❌ 或 🟡。Sortly 只拍照不辨識，Lens 辨識但不入庫——這是明顯空白。
- **AI 收納建議**全欄掛零。整個品類沒有任何 app 真的回答「我的東西應該怎麼放」。
- 訂閱制已是主流（7/12），消費者付費教育已完成。

## 第三部分：機會缺口分析

### 差異化機會點（3-5 個 angle）

1. **「拍照即入庫 + 自動分類」是品類空白**
   Sortly 要使用者手動 key，Lens 認得但不存。把 GPT-4V / Gemini Vision 等級的辨識直接綡進 inventory flow，就是一個沒人做的 0→1。

2. **AI 收納建議是真正的藍海，但要綡「具體空間」才有用**
   光說「衣服分顏色掛」是 Pinterest 等級。我們的差異化必須是「掃你家衣櫃 → 給你你家衣櫃的方案」。把 Magicplan 的空間掃描 + 物品辨識 + LLM 推薦串起來。

3. **「買收納盒」這個 high-intent moment 沒人收割**
   消費者整理時最痛的就是「我需要什麼尺寸的盒子」。Houzz 賣設計感，IKEA 賣自家。沒人做「依你家空間尺寸 + 你的物品量，推薦該買哪幾個收納盒」的精準導購——這同時是商業模式。

4. **季節輪替/換季提醒是被低估的 retention hook**
   Sortly 有保固提醒但很制式。「夏天到了，你冬衣該收起來，這 12 件建議裝進這 2 個箱子放在衣櫃上層」這種 contextual nudge 才是讓 app 留下來的理由。

5. **家庭協作 + 角色（「誰的東西」）**
   Sortly 的協作偏 B2B。家庭場景的真正痛點是「老公的襪子不要混到我的抽屜」——把物品 owner 和共用空間的 ACL 做對，是 family TA 的鉤子。

### 最大威脅

**Sortly 是最大威脅，但威脅有限。**
- 為什麼像：他們最接近「物品 inventory + 訂閱制 + 家庭」這個組合。
- 為什麼有限：他們 6 年沒有大改架構，AI 完全沒進場，UX 是 2018 年的味道。只要我們在拍照識物 + AI 推薦上做出體感差距，就有空間切走他們的 family 用戶。
- **次要威脅**：IKEA / Amazon 哪天決定把 AR + AI 推薦 + inventory 整起來。但大公司動作慢，這是 2-3 年的時間窗。

### MVP 優先順序（依市場驗證的 unmet need）

| 排序 | 功能 | 為什麼是這個順序 |
|---|---|---|
| **P0** | 拍照識物 + 自動分類 + 物品清單 | 整個 app 的入口，且 Sortly 沒做、Lens 沒接 inventory，是最大缺口。沒這個其他都白搭。 |
| **P0** | 基礎標籤 / 房間-收納位置兩級結構 | 為後續 AI 推薦準備結構化資料。先不要做完整 2D 平面圖。 |
| **P1** | AI 收納建議（先文字 + 圖卡，不做 3D） | 在 P0 累積物品資料後馬上接，是付費轉換的 hero feature。3D 太重，MVP 跳過。 |
| **P1** | 收納用品購物清單（先做「建議清單」，不做交易閉環） | 用 affiliate / 外連先驗證 intent，不要一開始做商城。 |
| **P2** | 家人共享 | 留下家庭用戶的 retention 機制，但單人能跑通才做多人。 |
| **P2** | 換季 / 保固提醒 | retention loop，等 DAU 數據出來再決定通知策略。 |
| **P3** | 2D / 3D 空間規劃 | Planner 5D 已經把這條路做爛了，我們不要正面對撞。要做就用 Magicplan 風格的相機掃描而不是手繪。 |

### 給創辦人的 actionable 結論

- **不要把自己定位成 "Sortly + AI"，要定位成 "AI 收納顧問，inventory 只是 side effect"**。前者只是功能加法，後者是品類重定義。
- **第一個版本只要做對一件事：使用者拍 10 張照片，3 分鐘後得到一個具體的「你家的收納改造方案 + 該買的 3 個收納盒」**。其餘都是支援這個 magic moment 的鷹架。
- ~~**收費點放在「生成方案」而不是「儲存物品」**。inventory 免費無限，AI 推薦次數收費——讓免費用戶幫你做資料，付費用戶買洞察。~~ **v4 撤銷**（見 ADR-009）— 未達 PMF 前不談付費。
- **避開 3D 規劃這個坑**。資源不夠又打不贏 Planner 5D，且不是用戶真正要的東西。

## v2 補充：台灣本土觀察（2026-05-17 加入）

來源：台灣收納全景研究報告 2026-05。

### 台灣本土 app 是藍海

**台灣本土搜尋並未發現具規模的整理 app**，僅有：
- 「在那兒」（個人開發者）— 小型工具
- ReLife、HoHo 好服務 — 服務媒合平台，不是工具型 app

**戰略意涵**：
- 國際整理 app 沒有中文化、沒有華人文化處理（祖傳物 / 集點 / 風水 / 多代同堂）、沒有台灣氣候（防潮 / 米蟲）、沒有方法論引擎
- Amber Stash 的差異化 = **方法論引擎（6 派內建）+ 華人在地化 + 台灣氣候規則 + 銀髮 / 小坪數專門模式**
- 不要直接打 Whering / Acloset（衣物專），打**「全屋方法論顧問」缺口**

### 衣物管理 app 對標（v4 新增）

| 名稱 | 國 | 商業模式 | 強在 | 弱在 |
|---|---|---|---|---|
| Whering | 英 | Freemium £4.99/月 | 永續導向、環境影響追蹤、shuffle | 純衣物、無方法論 |
| Acloset | 韓 | Freemium $3.99-9.99/月 | AI 功能最豐富、可從 H&M/ZARA/Nike 加入單品 | 韓系 UX、無在地化 |
| Cladwell | 美 | 訂閱 $7.99-9.99/月 | 膠囊衣櫥 + 2024 加入 3D body scan | 美式風格、無亞洲身形 |
| Stylebook | 美（iOS only） | 一次性 $4.99 | 買斷派偏好 | iOS only、UX 舊 |

**Amber Stash 衣物 mode（M5.5-T1.9）的差異化**：
- 賴庭荷「衣櫥醫生」方法論（中性 / LGBTQ+ 友善穿搭）
- 5-4-3-2-1 膠囊衣櫥公式
- 三種摺法（直立 / 口袋 / 軍人）
- 台灣防潮四要 + 衣架統一建議
- 與全屋 inventory 整合（衣物只是 category 之一，不獨立）

### 物品盤點 app 對標

| 名稱 | 商業模式 | 強在 | 弱在 |
|---|---|---|---|
| Sortly | Freemium / $24-49/月 | QR/條碼掃描、自訂欄位 | 美系 B2B + 收藏家，家庭 UX 弱 |
| Encircle | 免費版 2025/12/17 終止 | 保險導向 | 退出消費者市場 |
| Dib / Scanlily / Vorby | 訂閱 | AI 拍照辨識 + 估值（2025-2026 新世代）| 新進、生態未成熟 |

### 整理產業數字（2026 台灣）

- 整理師時薪：新手 NT$ 200-525 / 一般 NT$ 600-1,200 / 知名 NT$ 800-2,000
- 居家整聊室：兩人一組 NT$ 1,300/hr，4hr 起 = NT$ 5,200
- 廖心筠 1 對 1 線上 90 分：NT$ 1,380
- Hahow 課程：何安蒔 NT$ 1,580 賣出 27,931 學員；廖心筠 NT$ 1,686
- 居家整聊室 2024 募資 NT$ 5,000 萬，累計 10,000+ 家庭服務
- KonMari Consultant 國際課程：USD 2,000-2,500 + 年費 USD 500

**戰略意涵**（給 v5 變現考慮，**v4 不做**）：
- 整理師媒合是真實市場（10,000+ 家庭 / 年只有居家整聊室）
- 服務客單價高（NT$ 5,200-20,000）→ media 抽 5-10% 即可永續
- 證照培訓也是一條線（v6 候選）
- 詳細設計見 `docs/v5-monetization-redesign.md`

### 心理 / 文化獨特性（沒競品做到）

- **囤積症** 在台灣 DSM-5 / ICD-11 認可，但無國際 app 為此設計
- **華人 8 大文化包袱**（節儉 / 孝道 / 風水 / 多代 / 集點…）國際 app 完全不處理
- **超高齡社會 2026**（4.8 萬列冊獨居 / 估 40 萬）+ 遺物整理需求 — Amber Stash `elder-zh` 方法論已預備
- **小坪數 / 租屋**台灣典型住房 — Amber Stash `micro-rental-zh` 已預備

### v4 修訂結論

| 戰略 | v1 立場 | v4 修訂 |
|---|---|---|
