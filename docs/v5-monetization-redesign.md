# v5 變現重設計：整理師媒合（取代 v3 訂閱模式）

> 撰寫日期：2026-05-17
> 狀態：**設計文件 / 未實作**。v4 期間嚴格遵守 ADR-009「先做好用 app」原則，本文件僅為 v5 評估依據。
> 觸發：M6 使用者煙霧測試結果若驗證 PMF，才啟動本路線。

---

## 背景：為什麼放棄 v3 訂閱模式

v3 規劃過三條變現線：
- A · AI 推薦進階訂閱（月費）
- B · 客製收納箱直營（一次性購買）
- C · 收納師方法論授權 / 訂閱（月費 / 一次性）

ADR-009 已下架全部 — 因為「未達 PMF 前談付費鉤子會傷害把 app 做好用」。

**本文件提出 v5 的替代路徑**：不是讓 app 變付費，而是讓 app **成為整理師服務的入口**。

---

## 核心洞察（來自 2026-05 台灣收納全景報告）

### 整理師服務市場是真實的

| 指標 | 數字 |
|---|---|
| 居家整聊室累計服務家庭 | 10,000+ |
| 居家整聊室 2024 募資 | NT$ 5,000 萬 |
| 整理師時薪範圍 | NT$ 200 - 2,000 |
| 整聊室 4hr 起跳 | NT$ 5,200 |
| 廖心筠線上 90 分 | NT$ 1,380 |
| 何安蒔 Hahow 課（NT$ 1,580）已售 | 27,931 人 |

**這不是早期市場 — 是已驗證的需求**。

### 已有的媒合平台（競品 / 參考）

- **ReLife** — 末羊子 × Blair 整理收納學院，自家整理師接案
- **HoHo 好服務** — 多元生活服務媒合（含整理）
- **居家整聊室** — 自有 + 與信義居家簽長期合約

**機會點**：這些平台都不是「使用 app 蒐集物品資料 → 整理師接手後有資料底」的型態。整理師到府時要從零理解客戶家裡狀況，浪費 30-60 分鐘。

## v5 變現模型設計：三條線

### 線 1 · 整理師媒合（最該做）

**機制**：
- 使用者用 Amber Stash 蒐集 inventory（免費）
- 在 app 內預約整理師到府服務
- **整理師到府前能 read-only 看使用者 inventory**（節省 30-60 分鐘理解時間）
- Amber Stash 抽 5-10% 服務費

**為什麼這個 angle 對**：
- ✅ 對使用者：不用重複講家裡狀況，整理師直接帶方案來
- ✅ 對整理師：縮短 ramp-up、客單價可能上調 10-20%
- ✅ 對 Amber Stash：5% × NT$ 8,000 × 1000 case/年 = NT$ 400 萬，是有意義的單位經濟

**單位經濟試算**（保守）：
- 平均單次服務：NT$ 8,000（4hr × NT$ 1,300 + 升級到中型工作）
- Amber Stash 抽成 7%：NT$ 560 / case
- 目標年成交 1,000 case → NT$ 56 萬營收
- 目標年成交 5,000 case → NT$ 280 萬營收
- 比較 v3 訂閱模式：要達到同營收需 NT$ 79/月 × 5,000 訂閱 × 12 = NT$ 474 萬（但留存率假設樂觀，實際整理 app 訂閱留存通常 < 30%）

**風險**：
- 整理師可能繞過 app 私下接案
  - 對策：把預約流程做順、保留付款 / 評價 / 糾紛處理在 app 內 → 整理師不脫離 app 反而較省事
- 媒合品質決定一切（介紹爛整理師 = app 招牌毀）
  - 對策：採邀請制不開放，先合作 5-10 位高品質、各方法論派別齊全的

### 線 2 · 整理師後台訂閱（B2B 補位）

**機制**：
- 整理師付月費（NT$ 500-1,500）獲得：
  - 服務區域曝光優先權
  - 帶入 Amber Stash 自家方法論引擎當「行銷話術 + 客戶教育素材」
  - 客戶 inventory pre-read（節省理解時間 = 提升 hourly 客單價）
  - 「Amber Stash 認證整理師」徽章
- 沒付費的整理師仍可接案，但無上述 perks

**規模試算**：
- 目標年內招 100 位付費整理師 × NT$ 800/月 × 12 = NT$ 96 萬
- 留存率高（工具上手後不會輕易換）

### 線 3 · 課程 / 認證（v6 候選）

**機制**：
- Hahow 模式 — Amber Stash 與整理師合作開課
- 課程附 app pro 功能（如 AI 識物次數上限、進階方法論）
- 抽 20-30%（業界 30-40% 是合理區間）

**規模試算**：
- 一門課 NT$ 1,580 × 賣 5,000 學員 = NT$ 790 萬 / 課
- 抽 25% = NT$ 197.5 萬 / 課

**不在 v5，留 v6+**

## v5 開發範圍預估

依「最小可行驗證」原則，v5 啟動條件 = M6 煙霧測試通過後。

**v5 P0**（必做）：
- 整理師 profile + 服務區域 + 方法論派別 schema
- 預約流程（時間 / 場域 / 預估時數 / 物品清單分享同意書）
- 整理師 read-only 客戶 inventory view
- 付款（金流 — 藍新 / 綠界）
- 服務後評價

**v5 P1**：
- 整理師後台訂閱 / 認證徽章
- 糾紛處理流程
- 重複預約（VIP 客戶）

**v5 P2**：
- 課程平台整合
- 跨方法論的「找哪派整理師最適合我」推薦

**工程估算**：v5 P0 約 6-8 週、需要金流整合（外部依賴）+ 法務（隱私 / 服務條款 / 仲介責任）。

## v4 → v5 過渡準備

v4 期間**禁止做**的事（避免破壞 ADR-009）：
- ❌ 寫任何 paywall / 訂閱 UI
- ❌ 對外宣傳「未來會有付費版」
- ❌ 與整理師簽任何合約

v4 期間**可以做**的準備（不影響使用者體驗）：
- ✅ Methodology 內建保留 author 欄位（已 ship）— 整理師認證後可直接掛
- ✅ Item / Space 資料可 export（為 v5 share-to-organizer 預備）— 暫無，加 export 功能屬 M0.5
- ✅ 建立整理師關係（非商業） — 邀請使用 Amber Stash 給回饋
- ✅ 觀察使用者是否會問「我可以找整理師嗎」 — 煙霧測試訪談題

---

## 不做的事（避免戰略漂移）

### 不做：app 本身訂閱付費
- 違反 ADR-009
- 整理 app 全球留存率低（< 30% / year），訂閱單位經濟不成立
- 變現線 1（媒合）的單位經濟更好

### 不做：自營整理師團隊
- 變成 service company，工程不是核心
- 居家整聊室已有 5,000 萬募資 + 2,000 位認證整聊師 — 規模優勢無法追上
- 平台戰略才是 software-defensible

### 不做：客製收納箱（v3 M7）
- 實體商品 = 庫存 + 物流 = 完全不同的公司型態
- 留作整理師服務的 upsell 子產品（由整理師決定推薦哪個工廠），不由 app 直營

## 決策觸發條件

**啟動 v5 線 1**（整理師媒合）的條件 — 全部成立才動工：

- [ ] M6 使用者煙霧測試完成（5-10 位非團隊使用者連用 2 週）
- [ ] ≥ 3 位使用者主動問「能不能找整理師」/「能不能分享給我家人」
- [ ] DAU 留存 30 天 ≥ 20%（基本門檻；整理 app 業界平均偏低）
- [ ] 取得至少 1 位中流整理師（如 Blair / 末羊子等級）的願意合作意向書

任一未達成 → 留在 v4，繼續打磨 app 本體。

## 給創辦人的決策建議

- v4 期間**完全不要碰** v5 設計（連聊都不要）— 戰略漂移風險
- 把這份文件當「**做完 M6 煙霧測試後再打開**」的封存
- 真要走 v5 時，先做線 1（整理師媒合）— 線 2 / 3 留待線 1 跑通才考慮
- 法律 / 金流 / 客服將是 v5 真正的瓶頸（不是工程），預留 3 個月 ramp-up
